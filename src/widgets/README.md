# widgets

- [`AggregateView.js`](./AggregateView.js): shows aggregate provenance across registered widgets.
- [`Chart.js`](./Chart.js): renders aggregate and temporal provenance charts.
- [`Checkbox.js`](./Checkbox.js): renders one checkbox inside a checkbox group.
- [`CheckboxGroup.js`](./CheckboxGroup.js): tracks a group of checkbox selections.
- [`InputText.js`](./InputText.js): tracks committed text input values.
- [`MultiSelectDropdown.js`](./MultiSelectDropdown.js): tracks multiple dropdown selections.
- [`ProvenanceButton.js`](./ProvenanceButton.js): opens a widget's provenance view.
- [`RadioButton.js`](./RadioButton.js): renders one option inside a radio group.
- [`RadioGroup.js`](./RadioGroup.js): tracks one selected radio option.
- [`RangeSlider.js`](./RangeSlider.js): tracks a two-handle numeric range.
- [`SingleSelectDropdown.js`](./SingleSelectDropdown.js): tracks one dropdown selection.
- [`SingleSlider.js`](./SingleSlider.js): tracks one numeric slider value.
- [`SuperProvenanceWidget.js`](./SuperProvenanceWidget.js): coordinates provenance across multiple widgets.
- [`TimelineVis.js`](./TimelineVis.js): renders selection history over time.
